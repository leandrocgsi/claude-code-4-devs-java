🚧 **Curso em pré-venda e em gravação.** Este é o repositório oficial de código-fonte da formação. Os módulos são adicionados progressivamente conforme as aulas são lançadas — hoje já estão disponíveis os códigos dos Módulos 02 e 04, descritos na tabela abaixo.

Este repositório reúne o código de **antes** e **depois** de cada aula, para que você acompanhe exatamente o que foi construído com o **Claude Code** em cada etapa: da introdução ao agente de IA até a evolução completa de uma API **Java** e **Spring Boot**, com persistência, validações, testes e deploy em produção.

---

## 📚 Sobre o Curso

- Escreva, debugue e evolua aplicações **Java** e **Spring Boot** até **10x mais rápido** usando **Claude Code**
- Domine **CLAUDE.md**, **MCP (Model Context Protocol)** e a criação de **Agentes de IA** aplicados a projetos reais
- Gerencie **janelas de contexto**, tokens e custos do Claude Code em sessões longas de desenvolvimento
- Construa uma aplicação **full stack** completa — com **Spring Security**, **JWT**, testes automatizados com **JUnit** e integração de e-mail com **SendGrid**
- Faça o **deploy em produção** de uma aplicação real com IA integrada

## 🎯 Para Quem é Este Curso

Formação voltada a desenvolvedores **Java pleno ou sênior** que já conhecem **Java**, **Orientação a Objetos** e, idealmente, **Spring Boot** e **REST APIs**. Experiência prévia com front-end (**React**, **Angular** ou **Vue.js**) ajuda, mas não é obrigatória.

> Este não é um curso introdutório de Java — para avaliar se o que o Claude Code está gerando está correto, é preciso já saber programar em Java.

## ⚡ Como Usar Este Repositório

```bash
# Clonar o repositório completo
git clone https://github.com/leandrocgsi/claude-code-4-devs-java.git
cd claude-code-4-devs-java

# Exemplo: rodar a versão "depois" da API Spring Boot do Módulo 04
cd 04_ClaudeCodeAndSpringBoot/01-SpringBoot-After/rest-with-spring-boot-and-java-erudio
mvn spring-boot:run

# Exemplo: abrir o site estático do Módulo 02
cd 02_IntroToClaudeCode/01-petshop-after
# abra o index.html no navegador, ou sirva com um servidor local
```

Cada módulo com código possui as pastas `Before` (estado inicial) e `After` (estado final da aula), para você comparar exatamente o que o Claude Code alterou.
